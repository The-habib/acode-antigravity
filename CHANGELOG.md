# Changelog

All notable changes to the `acode-antigravity` plugin will be documented in this file.

## [1.0.0] - 2026-08-12

### Added
- Initial release of Acode Antigravity plugin.
- Native execution support for Google Antigravity CLI (`agy`) inside Acode Terminal.
- Automated environment detection for Android `aarch64` and Alpine runtime.
- Acode Terminal API integration (`acode.require('terminal')`).
- Shell launcher tools (`agy`, `agy-setup`, `agy-check`, `agy-repair`, `agy-update`).
- Integrated Acode Command Palette commands and interactive status dialog UI.
- Persistent PATH configuration in `~/.bashrc`, `~/.profile`, and `~/.zshrc`.
